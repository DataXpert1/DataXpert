DataXpert 🚀
DataXpert is a scalable web application designed for real-time company analytics and financial metric predictions. Built for the PSB [SDE Track], it offers a robust portal for company searches, historical tracking, and interactive data visualization while ensuring security, scalability, and optimized performance.

🔥 Features
🛡️ Authentication & Security
Google and Social Media login
2FA implementation
Password recovery & update
📊 Real-Time Computation
Fetches company data based on user input
Performs key financial computations (stock price, revenue, expense, market share, diversity, etc.)
Growth & stability analysis with future predictions
Ensures a minimum 2-minute response time for real-time computations
📜 History & Data Retrieval
Stores all previous searches for instant retrieval
Precomputed results available for repeated queries
⚡ Scalability & Performance
Handles 100,000+ DAU and 1,000+ RPS
Optimized backend & frontend architecture
📈 Data Visualization
Interactive graphs, tables, and reports for easy insights
🏗️ Tech Stack
Frontend: Next.js, Tailwind CSS
Backend: Node.js, Express.js
Database: PostgreSQL with Sequelize
Caching: Redis for optimized history retrieval
Machine Learning: Python-based microservices for predictions
Security: JWT authentication, bcrypt for password hashing
🚀 Deployment
Designed for scalability, supporting containerized deployment with Docker, and cloud-based infrastructure for high availability.
